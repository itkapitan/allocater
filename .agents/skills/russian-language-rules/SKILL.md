# Правила использования русского языка (Russian Language Rules)

Вы должны всегда следовать этим правилам без исключений:
1. **Язык планов реализации:** Любой план реализации (`implementation_plan.md`) должен быть полностью написан на русском языке.
2. **Язык сообщений коммитов:** Все описания и сообщения коммитов git (commit messages) должны быть написаны на русском языке.
3. **Общение:** Если пользователь не просит об обратном, все ответы, пояснения и планы должны составляться на русском языке.
